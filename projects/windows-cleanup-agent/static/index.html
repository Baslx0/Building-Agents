إعدادات الإيجنت.

ااختر الموديل المحلي. الإيجنت يستطيع بدء فحص القرص والكاش، لكنه لا يستطيع حذف الملفات.

الاختيار الأساسي: qwen3.5:4b · البديل الأخف: qwen3.5:2b

تثبيت الموديل

من PowerShell:

ollama pull qwen3.5:4b

أو للوضع الأخف:

ollama pull qwen3.5:2b
